Vanilla Bow Tiers - Texture Templates (v0.1.7)

All normal item textures are now 16x16 RGBA PNGs with transparent backgrounds,
matching Minecraft's vanilla item-art pixel grid.

Files:
- iron_bow.png
- golden_bow.png
- diamond_bow.png
- netherite_bow.png
- iron_arrow.png
- golden_arrow.png
- diamond_arrow.png
- netherite_arrow.png

Editable copies:
  texture_templates/

Files used by the mod:
  src/main/resources/assets/vanilla_bow_tiers/textures/item/

Keep the filenames unchanged. Existing item model JSON files already reference
these texture names.

Bray-specific 3D/model textures are a separate compatibility concern and do
not require these base inventory textures to be 32x32.
